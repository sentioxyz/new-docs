Sentio Connect is a remote MCP server that speaks **Streamable HTTP** and **OAuth 2.1**. Any assistant that supports remote MCP servers with OAuth can use it. The server URL is always:

```text
https://connect.sentio.xyz/v1/mcp
```

You never paste an API key. The first time your assistant connects, it sends you to the Sentio Connect consent page, where you sign in (if you aren't already) and click **Allow connection**.

<Tab value="Claude" id="claude">

Works in Claude on the web, Claude Desktop and the Claude mobile apps.

![Adding Sentio Connect as a custom connector in Claude](/assets/connect-claude.gif)

1. Open **Settings → Connectors**, click **Add** and choose **Add custom connector**.
2. Enter a name (for example `Sentio Connect`) and the URL `https://connect.sentio.xyz/v1/mcp`, then click **Continue**.
3. Under **OAuth client**, keep **Register automatically** selected and click **Add**.
4. Click **Connect**. A browser window opens the Sentio Connect consent page — click **Allow connection**.
5. In a conversation, make sure the Sentio connector is enabled in the tools menu, then ask a question about your wallets.

Claude renders token balances and DeFi positions as interactive cards. Click a row in a card to chart that holding's 24h or 7d history.

</Tab>
<Tab value="ChatGPT" id="chatgpt">

![Adding Sentio Connect as an MCP app in ChatGPT](/assets/connect-chatgpt.gif)

1. Open **Plugins**, click **Add** and choose **Create MCP App**.
2. Enter a name (for example `Sentio Connect`), set the **Server URL** to `https://connect.sentio.xyz/v1/mcp` and choose **OAuth** as the authentication method.
3. Check **I understand and want to continue**, then click **Create**.
4. Click **Continue to Sentio Connect**. On the Sentio Connect consent page, click **Allow connection**.
5. Enable Sentio Connect in a conversation and ask a question about your wallets.

Like Claude, ChatGPT shows token balances and DeFi positions as interactive cards.

### Codex

Point Codex straight at the server and log in:

```bash
codex mcp add sentio --url https://connect.sentio.xyz/v1/mcp
codex mcp login sentio
```

Or install the Sentio Connect plugin, which bundles the server entry with a skill that teaches Codex when to use each tool:

```text
/plugin marketplace add sentioxyz/sentio-connector
/plugin install sentio-connector@sentio
```

Codex doesn't render interactive cards; tool results appear as text.

<Tab value="Grok" id="grok">

![Adding Sentio Connect as a custom connector in Grok](/assets/connect-grok.gif)

1. Go to [grok.com/connectors](https://grok.com/connectors), click **New Connector** and choose **Custom**.
2. Enter a name (for example `Sentio Connect`) and the **Server URL** `https://connect.sentio.xyz/v1/mcp`, then click **Add Connector**.
3. A Sentio Connect window opens. Click **Allow connection**.
4. Grok discovers the Sentio tools automatically. Enable the connector in a conversation and ask a question about your wallets.

On Grok Business and Enterprise, an admin may need to allow custom connectors first.

<Tab value="Other MCP clients" id="other-mcp-clients">

Configure a remote MCP server with:

| Setting | Value |
| --- | --- |
| Transport | Streamable HTTP |
| URL | `https://connect.sentio.xyz/v1/mcp` |
| Authentication | OAuth 2.1 (discovery + dynamic client registration + PKCE) |

Clients that only support local (stdio) servers can bridge with [`mcp-remote`](https://www.npmjs.com/package/mcp-remote):

```json
{
  "mcpServers": {
    "sentio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://connect.sentio.xyz/v1/mcp"]
    }
  }
}
```

## Read-only vs. read-write connections

A connection is granted one or both of these scopes:

| Scope | Allows |
| --- | --- |
| `mcp:read` | All read tools: balances, prices, portfolio value, tracked addresses, DeFi positions and history |
| `mcp:write` | Also `add_wallet_address` and `remove_wallet_address`, which change **only your own** tracked-address list |

Most assistants request both. If a client asks only for `mcp:read`, the write tools are hidden from its tool list and rejected if called.

## Disconnecting

To revoke access, remove the connector in your assistant's settings. Access tokens expire after one hour and refresh tokens after 30 days, so an assistant that is no longer used loses access on its own.
