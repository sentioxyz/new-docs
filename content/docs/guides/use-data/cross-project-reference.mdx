---

You can import other projects' data into another project and use the data in Data Studio, Dashboard and other places.

The imported projects could be either Sentio Processor or Subgraph Projects.

## Import projects

You can manage and import projects through **Project -> Data Source -> External Project**.

![](/assets/4f2abd2eed333d2d4fd82ce0b1e623c86cbe122db0425fc043afba788027354b-image.png)

And search to import projects:

<img src="/assets/f8b7baa80ba518b9e4e97ca11791f283db432765c55ab62973d059cf4b89712a-image.png" alt="" className="rounded-lg" style={{ width: '80%' }} />

You can import multiple projects at once. If you import one at a time, then you can choose to set an alias for the project for easier access later.

## Access External Data

Now in SQL Data Studio, you can see tables from other projects. You can freely query by joining data from all those projects.
