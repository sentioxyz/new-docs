We support creating notification channels for

* Email
* Webhook
* Slack
* Telegram
* PagerDuty
* Discord

![Creating Email Channel](/assets/createchannel.gif)

## Creating Slack Channel

You can follow UI instructions to perform Slack integration.

## Creating Telegram Channel

First type in a channel name and click the Create button, then you should see a tip on how to connect with our @sentio\_bot on Telegram.

## Creating PagerDuty Channel

You can follow UI instructions to perform Slack integration. First click the Connect button.

![](/assets/image-1-1-1-2-1.png)

After the authentication, choose a service you created in PagerDuty.

![](/assets/image-12.png)

## Creating Discord Channel

First create a webhook in a channel on your Discord server, copy the webhook URL.

![On Discord, Edit Channel > Integrations > Webhooks](/assets/f64fb9e1dddd31bede52894dc974927eb156cb4f1ec505e19713b975a824c7e7-image.png)

Then paste the webhook URL to Sentio.

![On Sentio, Channels > Add Channel](/assets/ab024290f8128f910867a6077ef77376cce9731a72bf072bf70deae50f9c473d-image.png)
