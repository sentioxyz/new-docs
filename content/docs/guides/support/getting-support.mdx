If you need assistance, you can reach out to us on our [Telegram](https://t.me/sentioxyz) or Slack channels.

To help us resolve your issues quickly and accurately, please make sure to include the following information when submitting a support request:

1. **Project URL**
   * Please include the URL of the Sentio project where the issue occurred.
   * *Example:* `https://app.sentio.xyz/sentio/coinbase`
   * **Including this in every support request is essential**.

2. **Processor Version**
   * Specify the version number of the processor you are using.
   * *Example:* Version 279 or 280.

3. **Data and How It's Generated**
   * If your question relates to specific data, please provide the request in text format.
   * Alternatively, explain how to identify the data in question (e.g., by specifying the message field in an event).
   * Please also include a link to the processor code where the data is generated.

Providing this information will enable our team to understand and address your query more efficiently.
