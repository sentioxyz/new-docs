---
title: "🔑 API Key"
---

Click the profile page on the **left bottom corner** and then create an [API key](https://app.sentio.xyz/profile/apikeys).

<br />

![Obtain API Key](/assets/apikey.gif)

> ⚠️
>
> Note, if you are making API calls on behalf of your org, create an organization API key instead, on the organization's API keys page: `https://app.sentio.xyz/organizations/<org>/apikeys`.

API keys can be used for API calls and login with command line. To login, copy the command given and execute in any terminal. Then you are all set.

```bash
npx -y -p @sentio/cli sentio login --api-key <your api key>
```
